# Python 中的属性

> 内容整理自 Python 学习笔记中的 DeepSeek 分享页。重复回答和网页占位符已清理。

属性（attribute）是对象拥有的数据或特征，通常通过点号访问。属性描述对象“有什么”，方法描述对象“能做什么”。

## 实例属性

实例属性属于特定对象，每个实例可以有不同的值：

```python
class Person:
    def __init__(self, name):
        self.name = name
        self.age = 0


p1 = Person("张三")
p1.age = 25
p2 = Person("李四")
p2.age = 30

print(p1.name, p1.age)
print(p2.name, p2.age)
```

## 类属性

类属性属于类本身，通常由所有实例共享：

```python
class Person:
    species = "人类"
    count = 0

    def __init__(self, name):
        self.name = name
        Person.count += 1

    @classmethod
    def get_count(cls):
        return cls.count


print(Person.species)
p1 = Person("张三")
p2 = Person("李四")
print(p1.species)
Person.species = "智人"
print(p2.species)
print(Person.get_count())
```

修改类属性会影响通过类读取该属性的实例，但如果给某个实例赋值同名属性，会在实例中创建自己的属性。

## 属性与方法

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2

    def calculate_area(self):
        return 3.14159 * self.radius ** 2


circle = Circle(5)
print(circle.radius)              # 属性
print(circle.area)                # 计算属性，不加括号
print(circle.calculate_area())    # 方法，需要括号
```

- 属性：描述对象状态。
- 方法：执行行为或操作。
- 计算属性：不需要参数、没有明显副作用的计算，可以使用 `@property`。

## 直接访问和修改

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance


account = BankAccount("张三", 1000)
print(account.balance)
account.balance = 1500
account.bank = "中国银行"  # 动态添加属性
```

## getter、setter 与 `@property`

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    def get_balance(self):
        return self._balance

    def set_balance(self, amount):
        if amount < 0:
            print("余额不能为负！")
        else:
            self._balance = amount
```

更 Pythonic 的方式是使用 `@property`：

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    @balance.setter
    def balance(self, amount):
        if amount < 0:
            raise ValueError("余额不能为负！")
        self._balance = amount

    @property
    def formatted_balance(self):
        return f"¥{self._balance:,.2f}"


account = BankAccount("张三", 1000)
print(account.balance)
account.balance = 1500
print(account.formatted_balance)
```

## 内置属性

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


person = Person("张三", 25)
print(person.__dict__)
print(person.__class__)
print(person.__module__)
print(Person.__name__)
print(Person.__bases__)
```

模块也有属性：

```python
import math

print(math.__name__)
print(math.pi)
print(math.sqrt)
```

## 动态属性管理

```python
class FlexibleObject:
    pass


obj = FlexibleObject()
obj.name = "动态对象"
obj.value = 100

print(hasattr(obj, "name"))
print(getattr(obj, "name", "默认值"))
print(getattr(obj, "missing", "默认值"))
setattr(obj, "new_attr", "新属性")
delattr(obj, "value")
print(obj.__dict__)
```

## `__slots__`

`__slots__` 可以限制实例允许拥有的属性，并减少实例的内存开销：

```python
class RestrictedObject:
    __slots__ = ["name", "age"]

    def __init__(self, name, age):
        self.name = name
        self.age = age


obj = RestrictedObject("张三", 25)
# obj.new_attr = "测试"  # AttributeError
print(hasattr(obj, "__dict__"))  # False
```

## 属性继承

```python
class Animal:
    def __init__(self, name):
        self.name = name
        self.category = "动物"


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
        self.category = "犬科"


dog = Dog("小黑", "拉布拉多")
print(dog.name)
print(dog.category)
print(dog.breed)
```

## 属性和方法的选择

| 需求 | 推荐形式 | 示例 |
| :--- | :--- | :--- |
| 存储数据 | 属性 | `person.name` |
| 无参数的计算结果 | `@property` | `circle.area` |
| 执行操作 | 方法 | `account.deposit(amount)` |
| 需要参数 | 方法 | `text.replace(old, new)` |
| 修改状态 | 方法或带验证的 setter | `account.deposit(amount)` |

## 实际应用

```python
class Product:
    def __init__(self, name, price, stock):
        self.name = name
        self._price = price
        self._stock = stock

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value <= 0:
            raise ValueError("价格必须为正数")
        self._price = value

    @property
    def stock(self):
        return self._stock

    @stock.setter
    def stock(self, value):
        if value < 0:
            raise ValueError("库存不能为负")
        self._stock = value

    @property
    def value_in_stock(self):
        return self.price * self.stock


product = Product("笔记本电脑", 5999.99, 10)
print(product.value_in_stock)
product.stock = 8
```

## 总结

- 属性描述对象的状态或特征。
- 普通属性适合存储数据。
- `@property` 适合无参数、无副作用的计算结果。
- 需要执行复杂逻辑、接受参数或产生副作用时，应使用方法。
- 单下划线属性是“内部使用”的约定，不是真正的访问控制。
