# Python 类详解

> 内容整理自 Python 学习笔记中的 DeepSeek 分享页。重复回答和网页占位符已清理。

类（class）是创建对象的蓝图，定义对象具有的属性和行为。它是面向对象编程中实现封装、继承和多态的基础。

## 定义和实例化

```python
class MyClass:
    pass


my_instance = MyClass()
```

类名通常使用驼峰命名法。实例通过类名加圆括号创建。

## 类属性、实例属性和实例方法

```python
class MyClass:
    class_attribute = "类属性"

    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, my name is {self.name}"


instance = MyClass("Alice")
print(MyClass.class_attribute)
print(instance.name)
print(instance.greet())
```

类属性属于类并可被实例共享；实例属性属于具体对象；实例方法的第一个参数通常是 `self`。

## 类方法

类方法使用 `@classmethod`，第一个参数是 `cls`，表示类本身：

```python
class Counter:
    count = 0

    def __init__(self):
        type(self).count += 1

    @classmethod
    def get_count(cls):
        return cls.count


Counter()
Counter()
print(Counter.get_count())
```

类方法也常用作替代构造函数：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_string(cls, value):
        name, age = value.split(",")
        return cls(name, int(age))


person = Person.from_string("张三,25")
```

## 静态方法

静态方法使用 `@staticmethod`，不需要 `self` 或 `cls`，通常用于与实例状态无关的工具函数：

```python
class MathUtils:
    @staticmethod
    def add(x, y):
        return x + y

    @staticmethod
    def factorial(n):
        result = 1
        for value in range(1, n + 1):
            result *= value
        return result
```

## 特殊方法

特殊方法通常以双下划线开头和结尾，用来让类接入 Python 的语言协议：

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __len__(self):
        return 2

    def __getitem__(self, index):
        if index == 0:
            return self.x
        if index == 1:
            return self.y
        raise IndexError("索引超出范围")

    def __call__(self):
        return f"向量({self.x}, {self.y})"
```

常见特殊方法包括 `__init__`、`__str__`、`__repr__`、`__add__`、`__len__`、`__getitem__` 和 `__call__`。

## 继承

子类可以继承父类的属性和方法，也可以重写或扩展它们：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("子类必须实现此方法")

    def move(self):
        print(f"{self.name} 在移动")


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

    def speak(self):
        return "汪汪！"

    def fetch(self):
        print(f"{self.name} 在接飞盘")


dog = Dog("旺财", "金毛")
print(dog.speak())
dog.move()
```

Python 也支持多继承：

```python
class Flyable:
    def fly(self):
        print("飞起来了")


class Swimmable:
    def swim(self):
        print("游起来了")


class Duck(Animal, Flyable, Swimmable):
    def speak(self):
        return "嘎嘎！"
```

## 封装

Python 通过命名约定表达访问意图：

- 无下划线：公开成员。
- 一个下划线：内部或受保护成员的约定。
- 两个下划线：触发名称改写，通常用于避免名称冲突。

```python
class MyClass:
    def __init__(self):
        self.public = "public"
        self._protected = "protected"
        self.__private = "private"


instance = MyClass()
print(instance.public)
print(instance._protected)
# print(instance.__private)  # AttributeError
print(instance._MyClass__private)  # 可以访问，但不推荐
```

更完整的封装示例：

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return True
        return False

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            return True
        return False

    @property
    def balance(self):
        return self.__balance
```

## 抽象基类

抽象基类可以规定子类必须实现的接口：

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

    @abstractmethod
    def perimeter(self):
        pass

    def description(self):
        return "这是一个形状"


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14159 * self.radius ** 2

    def perimeter(self):
        return 2 * 3.14159 * self.radius
```

## 混入类（Mixin）

Mixin 用于为类提供一组可复用的辅助能力：

```python
import json


class JSONMixin:
    def to_json(self):
        return json.dumps(self.__dict__)


class XMLMixin:
    def to_xml(self):
        parts = ["<object>"]
        for key, value in self.__dict__.items():
            parts.append(f"  <{key}>{value}</{key}>")
        parts.append("</object>")
        return "\n".join(parts)


class Person(JSONMixin, XMLMixin):
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

## 多态

多态表示不同类型的对象可以响应同一个方法名：

```python
class Dog:
    def speak(self):
        return "Woof!"


class Cat:
    def speak(self):
        return "Meow!"


def animal_sound(animal):
    return animal.speak()
```

调用者只需要关心对象提供 `speak()`，不必关心具体类型。

## 综合示例

```python
class Employee:
    company = "ABC 科技有限公司"
    employee_count = 0

    def __init__(self, name, position, salary):
        self.name = name
        self.position = position
        self.__salary = salary
        Employee.employee_count += 1
        self.employee_id = Employee.employee_count

    @property
    def salary(self):
        return f"薪资：{self.__salary} 元"

    @salary.setter
    def salary(self, value):
        if value < 0:
            raise ValueError("薪资不能为负数")
        self.__salary = value

    def work(self, hours=8):
        return f"{self.name} 工作了 {hours} 小时"

    @classmethod
    def get_company_info(cls):
        return f"公司：{cls.company}，员工总数：{cls.employee_count}"

    @staticmethod
    def calculate_bonus(salary, rating):
        return salary * {"A": 0.2, "B": 0.1}.get(rating, 0.05)

    def __str__(self):
        return f"员工 {self.name}，职位：{self.position}，ID：{self.employee_id}"


employee = Employee("张三", "工程师", 15000)
print(employee)
print(employee.work())
print(Employee.get_company_info())
```

## 最佳实践

1. 类名使用驼峰命名法。
2. 为类和方法编写文档字符串。
3. 让每个类保持单一职责。
4. 复杂系统中优先考虑组合，而不是滥用继承。
5. 通过公开接口保护内部状态。
6. 使用类型提示提高可读性。

```python
from typing import Optional


class User:
    def __init__(self, username: str, email: str, age: Optional[int] = None):
        self.username = username
        self.email = email
        self.age = age
```

合理使用类可以让代码更模块化、可维护和可重用。
